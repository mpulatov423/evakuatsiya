# Android Studio'siz APK olish

1. GitHub.com saytida akkaunt oching yoki kiring.
2. New repository yarating.
3. Ushbu loyiha papkasining hamma fayllarini GitHub repository'ga yuklang.
4. Repository'da **Actions** bo‘limiga kiring.
5. **Build Evakuatsiya APK** workflow'ini tanlab **Run workflow** bosing.
6. Build tugagach, workflow natijasidagi **evakuatsiya-debug-apk** artifact'ini yuklab oling.
7. ZIP ichidagi `app-debug.apk`ni telefonga yuborib o‘rnating.

Bu usulda Android Studio va Android SDK noutbukda ishlamaydi; build GitHub serverida bajariladi.
